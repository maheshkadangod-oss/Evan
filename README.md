# evanjetlee.com

Personal site for Evan David Lee, marketing growth partner and fractional CMO, founder of JetSpeedSocial in Naples, Florida.
Vite, GSAP, Lenis. No framework. Every page is pre-rendered to static HTML at build time.

## Edit the words
All copy and numbers live in `src/content.js`. Numbers come from the "Case Studies SEO & PPC | 2026 JSS" deck.
Lines marked `CONFIRM` need Evan's sign-off before launch.

## How it is built
- `src/render.js` turns content into HTML. `vite.config.js` runs it at build time, so crawlers see full text.
- `src/seo.js` writes the schema (Person, ProfessionalService/LocalBusiness, ProfilePage, FAQPage, ItemList,
  Article and BreadcrumbList on case pages), plus `sitemap.xml`, `robots.txt` and `llms.txt`.
- Each featured case study gets its own page at `/work/<slug>/` with breadcrumbs.
- `src/charts.js` draws the result charts as SVG. `src/us-map.js` is generated by `node scripts/build-map.mjs`.
- `src/aurora.js` is the orange waterfall aurora behind the page.
- `src/main.js` only adds motion: reveals, chart drawing, map routes, smooth scroll.

## Photos
Originals are in `source-photos/`. The site uses processed versions in `public/img/`.
Swap in new photos with the same file names to upgrade the look. `public/og.jpg` is the social share image.

## Run locally
```
npm install
npm run dev
```

## Deploy
Import this repo in Vercel. It detects Vite (build `npm run build`, output `dist`). Every push deploys.
After the domain points to Vercel, submit `https://evanjetlee.com/sitemap.xml` in Google Search Console.
